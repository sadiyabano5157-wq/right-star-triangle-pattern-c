# ⭐ Right Side Star Triangle Pattern in C

## 📌 Description
This program prints a right aligned star triangle pattern using nested loops in C language.

---

## 🧠 Concepts Used
- Nested loops
- Outer loop for rows
- Inner loops for spaces and stars

---

## ⚙️ Logic

- First inner loop prints spaces
- Second inner loop prints stars
- Spaces decrease and stars increase in each row

---

## 💻 Language Used
- C Programming Language
